# 抖音一键拉黑插件
## 产品概述
针对抖音原生拉黑流程冗余、操作路径繁琐、使用场景受限等问题开发的增强工具。摒弃多层页面跳转与手动逐级点击的传统模式，依托底层接口调用实现一键极速拉黑，全面覆盖平台主流使用场景，同时新增弹幕右键溯源功能，大幅提升使用效率与场景实用性。

## 现存问题对比
| 使用痛点 | 官方原生操作 | 本插件能力 |
| ---- | ---- | ---- |
| 操作耗时 | 需跳转2至3级页面，单次操作耗时5秒以上 | 单次点击即可完成操作，响应无延迟 |
| 操作路径 | 必须进入用户主页，逐层打开菜单执行拉黑 | 功能入口常驻可视区域，无需切换页面 |
| 适用场景 | 仅支持从用户主页发起拉黑操作 | 推荐流、视频详情页、评论区、直播间全场景适配 |

## 核心能力
1. **极速接口调用**
直接调用平台内部屏蔽接口，不依赖模拟点击与页面渲染等待，摆脱页面跳转限制，指令下发与执行同步完成，执行效率远高于原生流程。

2. **全场景功能覆盖**
功能入口根据页面形态自适应展示，推荐视频互动区、视频作者信息栏、评论条目、直播间内均配备独立操作入口，全场景均可快速执行拉黑操作。

3. **界面原生适配**
界面元素遵循平台视觉规范设计，状态标识清晰区分正常、已拉黑状态，与原生界面深度融合，无视觉干扰，不遮挡原有内容展示。

4. **高精度用户数据解析**
可从页面地址、DOM节点、页面初始化数据、服务端渲染数据及内嵌框架中多维度提取用户唯一标识，数据识别准确率高，保障功能稳定执行。

5. **自定义快捷按键**
支持自主配置操作快捷键，可按需绑定组合键、单键等多种按键方案，进一步简化操作步骤，适配不同使用习惯。

6. **多层请求防护机制**
自动适配平台各类请求签名规则，集成XHR、Fetch、专属网络请求三重调用方案，规避接口校验限制，保证拉黑、解除拉黑指令稳定执行。

7. **操作可逆设计**
已屏蔽用户可再次点击功能按钮解除拉黑，操作可回滚，有效避免误操作带来的问题。

8. **弹幕右键溯源（新增）**
新增弹幕右键菜单功能，在弹幕内容上点击右键，可直接跳转至对应用户主页。快速定位弹幕发布者，便于追溯言论来源，针对性处理不良发言、对立引战等内容。
