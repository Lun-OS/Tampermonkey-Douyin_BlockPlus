# 抖音一键拉黑
推荐🌟🌟🌟🌟🌟

刷抖音终于可以像呼吸一样简单——遇到不喜欢的用户，**0.01 秒**点一下按钮就能永久屏蔽，再也不用忍受官方那套“三点头像→右上角菜单→拉黑→确认”的繁琐流程。

## ✨ 为什么你需要它？

| 痛点 | 官方操作 | 本脚本 |
|------|---------|--------|
| 拉黑耗时 | 跳转 2–3 个页面，至少 5 秒 | **点一下，瞬间完成** |
| 操作复杂度 | 必须进入主页 → 菜单 → 拉黑 | **按钮永远在你手边** |
| 覆盖范围 | 仅主页入口 | **推荐流、视频详情、评论区、直播间** |

## 🚀 核心功能

- **⏱️ 0.01 秒极速拉黑**  
  直接调用抖音内部屏蔽接口，不等页面跳转、不依赖模拟点击，体验如同原生功能。

- **🌐 四大场景全覆盖**
  - 推荐视频流：右侧互动区自动出现拉黑按钮  
  - 视频详情页：作者信息旁专属入口  
  - 评论区：每条评论自带迷你拉黑图标  

- **🎨 原生级 UI 融入**  
  毛玻璃按钮、红色高亮、已拉黑状态实时变色，完美融入抖音界面，不突兀、不遮挡。

- **🔄 智能识别人物**  
  自动从 URL、DOM、`__INITIAL_STATE__`、`__SSR_DATA__` 甚至 iframe 中精准提取用户 `sec_uid`，成功率极高。

- **⌨️ 自定义快捷键设置**  
  右键拉黑图标或原版快捷键设置即可打开设置快捷键支持多种功能快捷键（如ctrl+B、Q、F4等等）方便快捷易操作

- **🛡️ 稳定签名与多重请求保障**  
  自动适配 `X-Bogus`、`_byted_acrawler` 等签名机制，同时内置页面 XHR、Fetch、GM_xmlhttpRequest 三重请求策略，确保每次拉黑/解除都成功。

- **👆 即点即解**  
  已拉黑用户再次点击按钮即可解除，操作可逆，不会误封。
